# Third-party license texts

本目录保存 PotreeOSGViewer 直接依赖和内置第三方资源的许可证文本或版权声明：

- `Qt-LGPL-3.0.txt` 与 `GPL-3.0.txt`：Qt 开源版本的许可文本。
- `OpenSceneGraph-LICENSE.txt`：OpenSceneGraph Public License 1.0。
- `osgQt-LICENSE.txt`：OpenSceneGraph Public License 0.0。
- `Potree-LICENSE.txt`：Potree 许可证。
- `PotreeConverter-LICENSE.txt`：PotreeConverter 许可证。
- `Apache-2.0.txt` 与 `Turbo-NOTICE.txt`：Google Turbo colormap 的许可证和声明。

这些文件仅覆盖当前已知的直接依赖和内置资源。发布包含 OSG 插件或其他 DLL 的
二进制包时，还必须根据实际打包内容补充全部传递依赖的许可证。
